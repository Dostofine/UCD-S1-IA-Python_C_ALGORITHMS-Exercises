un nombre négatif et affiche le nombre d’entiers pairs, le nombre d’entiers impairs ainsi que le
nombre total d’entiers saisis.

                N_pair=N_pair+1
            sinon
                N_impair=N_impair+1
            fin si 
        fin si
    jusqu'a (N<0)
    ecrire("le nombre total d’entiers saisis est ",N_total)
    ecrire("le nombre d’entiers pairs est ",N_pair)
    ecrire(" le nombre d’entiers impairs est ",N_impair)
